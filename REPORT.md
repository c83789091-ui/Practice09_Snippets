# Отчет по практической работе №9

## Тема

Создание и использование сниппетов программного кода.

## Вариант

Вариант 1 - сниппет `prog` для формирования структуры консольного проекта.

Дополнительно созданы два своих сниппета:

- `readint` - ввод целого числа с проверкой;
- `pause` - пауза в консольной программе.

## Цель работы

Изучить назначение сниппетов и создать собственные шаблоны кода для языка C#.

## Краткая теория

Сниппет - это заранее подготовленный фрагмент кода, который можно быстро вставить в программу. Сниппеты экономят время и помогают не писать часто повторяющийся код вручную.

В Visual Studio сниппеты можно импортировать через меню Tools - Code Snippets Manager - Import.

## Ход решения задачи

### 1. Создание сниппета prog

Был создан файл `prog.snippet`. Он формирует базовую структуру консольной программы:

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
    }
}
```

Этот сниппет соответствует варианту 1.

### 2. Создание сниппета readint

Был создан дополнительный сниппет `readint`. Он нужен для ввода целого числа с проверкой через `int.TryParse`.

Такой код полезен, потому что ввод чисел часто используется в консольных программах.

### 3. Создание сниппета pause

Был создан дополнительный сниппет `pause`. Он выводит сообщение и вызывает `Console.ReadKey()`, чтобы консоль не закрывалась сразу.

### 4. Создание демонстрационной программы

Для проверки создан файл `Program.cs`. Он выводит информацию о практической, просит ввести имя, выводит приветствие и случайное число.

## Файлы сниппетов

Сниппеты находятся в папке `Snippets`:

- `prog.snippet`;
- `readint.snippet`;
- `pause.snippet`.

## Результат работы программы

Программа сообщает, какие сниппеты созданы, просит ввести имя и выводит случайное число:

```text
Практическая 9. Сниппеты.
Вариант 1 - сниппет prog для структуры консольной программы.
Также сделаны два своих сниппета: readint и pause.
```

## Вывод

В ходе работы были созданы три сниппета для C#. Основной сниппет `prog` соответствует варианту 1, а дополнительные сниппеты `readint` и `pause` показывают, как можно выносить часто используемые фрагменты кода в отдельные шаблоны.
